# Symbol -> SymbolCategory mappings: what a call-stack frame IS, for colouring and for hiding infrastructure.
#
# Pipe-delimited: Module|Class|Function|Category. Lines starting with # and blank lines are ignored.
#   - Matching per field: "CQScan" = exact (case-insensitive), "CQScan*" = starts-with, "*Scan" = ends-with,
#     "*CQScan*" = contains, "*" = any.
#   - Category must be a SymbolCategory enum name. A row whose category is not one is skipped, which is also how the
#     header below is discarded.
#   - The most specific matching rule wins: an exact field beats any glob, a longer glob beats a shorter one, and
#     function is weighted highest and breaks ties.
#
# Which plan operator a frame belongs to lives in Operators.txt, and where a unit of storage work begins in Barriers.txt
# — both were columns here and neither survived contact. One rule wins here, on category specificity, and carried
# whatever else it happened to hold: adding a rule to colour a frame could silently delete an operator boundary, and the
# only defence was repeating the boundary on every rule that might win.
